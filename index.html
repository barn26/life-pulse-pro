Оновити дані

Оскільки програми можуть працювати з різних сайтів або локальних файлів, вони не завжди можуть читати спільне сховище автоматично. Тут можна ввести два значення вручну або імпортувати файл JSON, якщо фінансова програма експортує такий знімок.

Імпортуй лише файл, у якому є ці два показники. LIFE PULSE не читає історію транзакцій.

Статус синхронізації

Дані ще не додано.

Автоматичне читання localStorage іншого сайту заблоковане браузером. Для автоматичної синхронізації потрібен спільний технічний міст або розміщення в одному origin із погодженим форматом даних.

CONTROL CENTER

Налаштування

Захист доступу

PIN не налаштовано.

PIN — це базове блокування інтерфейсу, а не шифрування даних. Не використовуй PIN від банківських чи інших важливих сервісів. Біометричний вхід залежить від браузера та платформи; звичайний HTML не гарантує нативний вхід за відбитком пальця.

Резервна копія

Експортуй дані у файл і збережи його в безпечному місці. Файл резервної копії міститиме твої локальні записи, тому не передавай його стороннім.

Офлайн-режим і встановлення

Перевіряємо доступність офлайн-кешу…

Для встановлення як PWA потрібні HTTPS (наприклад, GitHub Pages), manifest.json і service worker. Перший запуск потребує завантаження файлів; після кешування основний інтерфейс може працювати без мережі.
